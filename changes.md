The source code for Tk is managed by fossil.  Tk developers coordinate all
changes to the Tk source code at

> [Tk Source Code](https://core.tcl-lang.org/tk/)

Release Tk 9.2a0 arises from the check-in with tag `core-9-2-a0`.

Tk 9.2a0 continues the Tk 9.x series of releases.  The Tk 9.x series
do not support Tcl 8.6.  The Tk 9.2 series extends the Tcl 9.0 series.
To make use of Tk 9.2a0, first a Tcl 9.1 or 9.2 release must be present.
As new Tk features are developed, expect them to appear in Tk 9.2+, but not
in Tk 8.
